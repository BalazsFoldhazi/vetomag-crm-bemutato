# Vetőmag CRM — bemutató anyag

Agrár-kereskedésre épített ügyfélkezelő rendszer bemutatója: videók, képernyőképek,
prospektus és a promóciós szövegek.

**Bemutató oldal:** https://balazsfoldhazi.github.io/vetomag-crm-bemutato/

---

## Mi van ebben a tárolóban

| Mappa / fájl | Tartalom |
|---|---|
| `index.html` | A bemutató oldal (GitHub Pages ezt szolgálja ki) |
| `video/teaser.mp4` | 60 másodperces gyors bemutató |
| `video/teljes.mp4` | 3 perces részletes bemutató |
| `Vetomag-CRM-bemutato.pdf` | 8 oldalas, nyomtatható prospektus |
| `kepek/` | Képernyőképek a működő rendszerből |
| `szoveg/` | Promóciós szövegek (alapüzenet, modulok, megkeresések, weboldal-szöveg) |

## A szövegek

- [`szoveg/01-alapuzenet.md`](szoveg/01-alapuzenet.md) — a „mag": pozicionálás, három fő érv,
  kinek szól és kinek nem, hangnem, és amit sosem állítunk
- [`szoveg/02-modulok.md`](szoveg/02-modulok.md) — teljes modul-leltár, a tényleges
  menüszerkezet szerint
- [`szoveg/03-megkeresesek.md`](szoveg/03-megkeresesek.md) — kész e-mailek, közösségi posztok,
  telefonos felvezetés és a gyakori ellenvetések kezelése
- [`szoveg/04-weboldal.md`](szoveg/04-weboldal.md) — a bemutató oldal szövege külön szerkeszthetően

## Fontos

- **A képernyőképeken anonimizált demó-adatok szerepelnek.** A partnernevek, kapcsolattartók,
  telefonszámok és e-mail-címek kitaláltak; a felvételek egy külön, anonimizált
  demó-adatbázisból készültek. Valódi ügyféladat nem került az anyagba.
- **A CRM forráskódja nincs ebben a tárolóban** — az külön, privát tárolóban van.
- A MePAR-, támogatási és fajtaadatok tájékoztató jellegűek, hivatalos nyilvántartást
  nem helyettesítenek.
